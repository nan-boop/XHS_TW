# Obsidian 文档导航层

## 定位

Obsidian 是本 skill 的可选文档导航层，用来查看结构图、配置分支、保存规则、状态机和使用教程。它不是发布任务的唯一数据源，也不替代非 `C:` 盘保存库中的 `任务索引.json`、任务包和发布记录。

## 推荐目录

在用户的 Obsidian vault 中建立一个专题目录，例如：

```text
项目/
└─小红书发布 Skill/
  ├─00-小红书发布 Skill 索引.md
  ├─01-主流程结构图.md
  ├─02-按需任务配置与分支.md
  ├─03-本地保存库与检索.md
  ├─04-发布定时与防重复.md
  ├─05-状态机.md
  ├─06-使用教程.md
  ├─07-SKILL.md 对照.md
  ├─小红书发布 Skill.canvas
  └─assets/
```

## 同步规则

1. `SKILL.md` 是行为入口，Obsidian 页面是可读导航。
2. skill 的保存、发布和定时逻辑发生正式变化时，同步更新对应 Obsidian 页面。
3. 任务包发生保存、补充、发布或定时变更时，先更新本机 `任务清单.json` 与 `任务索引.json`；只有用户明确要求时，才把任务摘要整理进 Obsidian。
4. Obsidian 页面只放非敏感元数据、流程和链接，不放 Cookie、二维码 URL、验证码、密码、DPAPI 密文或共享盘凭据。
5. 用户没有指定 vault 时，只生成可导入的 Markdown 和 Canvas，不擅自写入未知位置。

## 使用方式

- 在 Obsidian 中打开 `00-小红书发布 Skill 索引` 作为入口。
- 从 `01-主流程结构图` 查看运行流程。
- 用户说“先储存、后补内容”时，跳到 `03-本地保存库与检索`。
- 用户说“发布”或“定时发布”时，先按 `04-发布定时与防重复` 检查索引和 `已发布` 标签。
- 出现异常状态时，查看 `05-状态机`，不要把“已保存”“已定时”“已上传”混写成“已发布”。
