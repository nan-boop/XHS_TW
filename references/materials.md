# 内网素材只读与本地处理

## 远端访问规则

`\\172.16.11.3` 及其所有子目录是只读源。允许的动作只有：

- 浏览目录和读取文件名
- 读取文件内容和元数据
- 预览图片、视频或文档
- 将已有文件复制到本机非 C 盘

以下动作一律禁止：新增目录或文件、删除、移动、剪切、重命名、编辑、裁切、压缩、转码、加水印、覆盖、替换、上传、回传、修改属性、修改权限、创建快捷方式、生成临时文件，以及任何可能改变远端状态的操作。工具行为不确定时先停止。

## 本地目录

由用户指定一个非 C 盘根目录；未指定时使用 `F:\注册机\小红书发布\`。有定时意向时先在该目录按发布时间搜文件夹，找到就沿用，找不到再按 `时间_型号` 新建。

```text
<非C盘根目录>\小红书发布\
├─任务索引.json
└─<时间>_<型号>\
   ├─产品资料\
   ├─图片\
   ├─视频\
   ├─文案笔记.md
   └─任务清单.json
```

手动配图时，用户可把图直接放进该包「图片」文件夹；给出的其他本机路径也要复制进「图片」后再验收。定时发布只引用该保存包，不能在计划时间前上传或发布。图还空着时只建包，不注册定时。

如果用户要求“先储存、后补笔记和图片”，先创建 `时间_型号` 目录、空的「图片」文件夹、根目录 `任务索引.json` 和包内 `任务清单.json`。占位包允许文案和图片为空，但必须标记 `已创建待补内容`，并把「图片」完整路径告诉用户；后续用户塞图后再执行哈希和逐项视觉验收。

共享盘搜索结果、来源清单和检查清单都写入本机目录。源路径和原始文件名保持不变；本机目标发生同名冲突时使用新文件名或新子目录，不能覆盖源文件。

## 复制与验证

1. 先按型号精确搜索，再按系列名、别名和场景词补搜；不整盘搬运。
2. 只复制与当前文案候选相关的文件到本机原始素材目录。
3. 复制动作必须是单向 `Copy-Item`/等价复制，不得移动、剪切或覆盖源文件。复制后核对文件数量、文件大小、扩展名和可打开性；记录源完整路径、目标路径、类型、尺寸或时长和复制状态。
4. 对源端可读取的文件执行 SHA-256 源/副本比对；网络源无法稳定哈希时，记录“源哈希未完成”，同时完成大小、扩展名、可打开性和本机副本哈希检查，不得声称完整性已通过。
5. 精选预览、候选原图和发布成品使用不同目录；精选预览与候选原图哈希应一致，经过裁切/压缩的发布成品必须标记为派生文件并保留来源记录。
6. 后续所有改名、整理、筛选标记、裁切、压缩、转码、加字和合成，只能在本机副本上执行。

## 逐项检查

每张图片和每条视频都要实际查看，不能只凭文件名判断。

- 图片：主体、方向、尺寸、清晰度、裁切、文字可读性、瑕疵、敏感信息，以及是否支撑文案中的具体句子。
- 视频：开头、主体和结尾，时长、方向、清晰度、声音/字幕、水印、卡顿，以及与文案的对应关系。

给每个文件写入 `保留 / 备选 / 淘汰` 和一句原因。按发布顺序把保留项复制到 `04_已筛选_待发布`；原始目录只保留复制来的工作副本。

## 源文件不可变与交付前验收

- 共享盘是只读源；浏览器预览、图片查看器和缩略图显示均不改变源文件或本机原图。
- 交付前再次确认：源路径仍可访问、源端未执行写操作、本机候选文件可打开、精选预览与候选原图内容一致、所有淘汰项仍保留在候选目录而未被误删。
- 清单至少包含：筛选日期、源/目标路径、原始文件名、字节大小、尺寸或时长、哈希状态、视觉检查结论、用户选择状态和回滚目录。
- 回滚只针对本机发布包；删除本机副本不会影响共享盘原图，禁止以任何删除远端文件的方式处理重复或错误素材。

## 小红书图片风格与逐图对比

图片筛选前做一次聚焦的网络检索，获取当前小红书图文的公开图片比例与构图参考，并把来源 URL、访问日期和采用的标准写入本机素材清单。网络资料只用于格式/视觉参考，不得作为产品参数来源，也不下载或回传远端图片。

当前优先标准：产品种草图文优先 3:4 竖版（常见目标 1080×1440），整组尽量统一比例；封面主体第一眼清晰，文字不贴边、不遮挡产品或人物，内页按“产品近景 → 使用场景 → 参数/细节”组织。1:1 方图可作为补充，横图或密集电商拼图只有在裁切后仍能完整表达时才保留。

逐一对比共享盘候选图与上述标准，至少记录：方向/比例、产品主体占比、是否为真实使用场景、文字可读性、水印或平台标识、清晰度、是否出现与产品简报冲突的参数/功效、与文案哪一句对应，以及最终 `保留 / 备选 / 淘汰` 结论。优先保留清晰的产品近景、自然使用场景和少量信息卡；淘汰仅有商品白底图的重复堆叠、主体过小、长图裁切会丢失信息、带其他平台水印或包含未确认/相互矛盾宣称的素材。
