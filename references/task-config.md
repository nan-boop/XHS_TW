# 小红书任务配置

写作规格见 [copy-types.md](copy-types.md)。登录成功后必须把「发给用户」发给对方，让对方自己选、自己填。不要把后半内部说明、英文名或字段 ID 发给用户。

## 首次使用引导

检测不到 `onboarding.completed=true`，或用户明确要求教学时，先发送：

```text
这是第一次使用小红书发布流程，我会带你走完一遍。
你将依次学会：配置任务 → 整理资料 → 写文案 → 放入图片 → 质检 → 保存/定时/发布。
本次请选择：模拟演练（不登录、不访问共享盘、不发布）或真实任务。
```

选择模拟演练时，只展示示例任务包、状态变化和操作提示，不执行登录、共享盘访问、素材复制、上传或发布。选择真实任务时，再进入登录门和下面的任务配置卡；每一步都说明当前状态、暂停原因和用户下一步操作。

## 发给用户

登录验收成功后，状态改为 `待任务配置`。选项说明用普通中文写在外面；【小红书任务配置】必须单独放进语言标记为 `text` 的围栏代码块，让界面显示成「纯文本」高亮卡片，方便复制。不要用表格、JSON、引用块，也不要把怎么选和模板塞进同一个代码块。用户已经说清的字段预填进代码块。发布已有任务且能定位目标时，不发这段，直接去找任务。

发给用户时按下面结构输出：

登录好了，可以开始做这篇了。

请看怎么选，选好后复制下面纯文本填给我。没想好的可以空着，或直接回「按默认」。
空着时：文案类型用种草分享，风格跟类型走，公开可见，不定时。

【怎么选】

- 动作：写文案（先出标题和正文，先不发）；保存（收到任务包里，先不发）；发布（做好后马上发）；定时发布（先存好，到你定的时间复查；资料或图片不齐就暂停并提醒，补齐后仍需用户确认才发）
- 产品：填型号和名字，例如 HU01 便携加湿器。还没定就写待补
- 文案类型：种草分享（日常安利）；官方品宣（按品牌口径讲卖点）；新品发布（先讲和以前有什么不同）；种草品宣综合（口语，卖点按方案）；测评对比（适不适合，不编实测）；教程指南（按步骤怎么用）；清单盘点（三到五个点）；问答避坑（先答顾虑）；活动促销（有规则才写优惠）
- 文案风格：口语种草（轻松聊天）；克制品宣（清楚、不夸张）；轻松综合（口语讲卖点）；步骤说明（短句、按点说）；问答克制（先答问题）
- 配图：自动（我去找店里的图）；手动（你把图给我）；混合（一部分你给，其余我找）；先空着（图还没好）
- 可见性：公开（所有人能看）；仅自己可见（先自己看）
- 定时：无（不预约）；要预约就填 `2026-09-20 20:00`。有定时意向时，先按这个时间去文件夹里找，例如 `2026-09-20_20-00_HU01`
- 文件夹：不填就去默认的 `F:\注册机\小红书发布\` 找；填了就按你指定的路径找

请复制下面纯文本，只改冒号右边：

````
```text
【小红书任务配置】
产品：
动作：
文案类型：
文案风格：
配图：
可见性：公开
定时：无
文件夹：
```
````

先把动作和产品定下来发我就行。

## 填写模板

字段名必须原样保留。冒号右边只填一个中文选项，不要把整段说明贴进去。

```text
【小红书任务配置】
产品：
动作：
文案类型：
文案风格：
配图：
可见性：公开
定时：无
文件夹：
```

## 内部对照（不要发给用户）

| 中文项 | 内部名 | 可选 | 默认 |
|---|---|---|---|
| 产品 | product | 型号+名称；未知写待补 | 无 |
| 动作 | action | 写文案 / 保存 / 发布 / 定时发布 | 无 |
| 文案类型 | copy_type | 种草分享 / 官方品宣 / 新品发布 / 种草品宣综合 / 测评对比 / 教程指南 / 清单盘点 / 问答避坑 / 活动促销 | 种草分享 |
| 文案风格 | copy_style | 口语种草 / 克制品宣 / 轻松综合 / 步骤说明 / 问答克制 | 跟类型走 |
| 配图 | assets.mode | 自动 / 手动 / 混合 / 先空着 | 创建时未说则再问一次 |
| 可见性 | visibility | 公开 / 仅自己可见 | 公开 |
| 定时 | schedule.at | 无 或 YYYY-MM-DD HH:mm | 无，时区上海 |

按动作：登录过程中不发引导。登录成功后，除「发布已有任务且已能定位」外都要发引导。写文案/保存需要产品。定时发布需要时间，没有时间就待补，不预约。

## 填写示例

只写文案：

```text
【小红书任务配置】
产品：HU01 便携加湿器
动作：写文案
文案类型：种草品宣综合
文案风格：轻松综合
配图：先空着
可见性：公开
定时：无
```

保存并定时：

```text
【小红书任务配置】
产品：HU01 便携加湿器
动作：定时发布
文案类型：官方品宣
文案风格：克制品宣
配图：自动
可见性：公开
定时：2026-09-20 20:00
```

## 解析规则

1. 只认中文项：产品、动作、文案类型、文案风格、配图、可见性、定时。不要用储存分类、任务名称、备注替代。
2. 冒号右边只保留一个值。
3. 未填类型 → `种草分享`；未填风格 → 跟类型走。
4. 动作=`定时发布` 且 定时=`无` → `待补资料`，不建包、不注册计划。
5. 动作=`定时发布` 且已有时间：先按该时间搜文件夹。用户填了文件夹就在指定位置搜，没填就在 `F:\注册机\小红书发布\` 搜。找到就沿用；找不到再新建 `YYYY-MM-DD_HH-mm_型号` 和「图片」文件夹。手动配图尚未补齐时可以保存任务，但不得注册可执行发布计划。
6. 写入 `任务清单.json`：`product`、`action`、`copy.copy_type`、`copy.copy_style`、`assets.mode`、`assets.drop_folder=图片`、`visibility`、`schedule.at`，时区固定 `Asia/Shanghai`。
7. 定时执行前复查：检查「图片」目录是否有用户补充、验证图片可打开性/哈希/视觉验收，并核对产品资料缺口。任一项未完成，状态改为 `待补资料` 或 `待素材检查`，提醒用户缺失项并等待“已补齐并确认发布”。
