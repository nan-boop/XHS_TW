# XHS_TW

小红书图文发布 skill，支持产品资料整理、文案分类、手动或自动配图、保存草稿和确认后的定时发布。

## 使用流程

首次加载时说“第一次使用”，skill 会逐步引导你完成任务配置、资料整理、文案生成、图片补充、质检和定时预览。确认文案与计划时间后即可创建定时任务；图片可以后补。

配置字段包括：产品、动作、文案类型、文案风格、配图、产品信息、小红书图文可见性、定时和文件夹。可见性写“公开”表示发布后的笔记对所有小红书用户可见。

同一份产品资料可以拆成内容 A、B、C 三篇笔记，并分别设置发布时间。每篇笔记拥有独立任务记录和图片目录。

选择手动配图时，把图片放入对应任务包的“图片”目录，或提供本机路径。定时到达时会先检查图片和资料；缺图则提醒、暂停发布，补齐并明确确认后才发布。

首次流程完成后，下次可直接复用模板，只修改产品、文案类型、风格、图片、可见性或发布时间等参数。

用户资料优先，资料缺口不自行脑补。保存成功不等于已定时，已定时也不等于已发布；只有取得平台成功信息或笔记链接才标记为已发布。

默认本地任务包目录：`F:\注册机\小红书发布\`。
